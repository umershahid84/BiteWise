# Operations & Troubleshooting Guide

`docs/TROUBLESHOOTING-GUIDE.md` is the platform's handbook for whoever runs it. Whenever you add or change a feature,
setting, environment variable, email, page, service, file location or fix, update the matching section of that guide
in the same commit and add a line to its Change log (newest first). Never put passwords or secret keys in it.
